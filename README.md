# PY2WWV Solar Dashboard

Automatically generated solar indicator image for the QRZ.com biography of PY2WWV.

- Source: NOAA Space Weather Prediction Center (SWPC)
- Schedule: every 3 hours (GitHub Actions scheduling may be delayed)
- `solar.png`: dashboard image generated by `generate.py`
- SFI and SSN are **monthly observed values**, not live instantaneous readings.
- Kp is the latest available planetary index.
- A index is displayed as `N/A` until a verified daily A-index source is integrated.

## Setup

1. Upload all project files to a public GitHub repository, preserving `.github/workflows/solar.yml`.
2. Open **Actions > Update solar dashboard > Run workflow**.
3. In **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. After the workflow completes and Pages deploys, the image is available at `https://skylinkras.github.io/py2wwv-solar/solar.png`.

To embed in QRZ.com HTML:

```html
<img src="https://skylinkras.github.io/py2wwv-solar/solar.png" alt="PY2WWV solar conditions" style="display:block;width:100%;max-width:100%;height:auto;border:0;" />
```

Note: GitHub Pages and browser caching can delay the appearance of new images.
